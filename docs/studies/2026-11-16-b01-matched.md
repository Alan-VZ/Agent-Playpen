# Two-round B01 study: four models per provider

The study completed all 240 scheduled cases: 221 attempted and 19 marked unavailable after OpenRouter explicitly rejected a request for daily free-quota exhaustion. Remaining OpenRouter cases were skipped as requested. No paid fallback, model substitution or automatic inference retry was used.

Study ID: `46ce32d5e085435fa52c66727fd874b5`. Execution source commit: `05746c54cb4fedac885ca0d037e75615175934f0`. Source fingerprint: `551e7a62d256fad121449b8216a2ab68cc83605d5563f0375f0ea656bc880805`.

## Method

Each provider retained the same four explicit model IDs across two rounds. Every model received B01 fixture seeds 1–5 in both arms, with temperature 0, 2,048 output tokens, ten ReAct iterations, and a shared 180-second task deadline. A parent termination grace period could extend elapsed wall time to approximately 190 seconds. Arm order was reversed for each matched seed in round two. Cloud request starts were paced by four seconds.

Arm A supplied the fixture documents directly without tools. It measured answer correctness only and could never earn a strict baseline pass. Arm B used the production ReAct agent, real fixture/calculator tools, and unchanged scorer. Each case used a fresh process and conversation; provider caches and model nondeterminism were uncontrolled. This study covered one synthetic task, not the entire five-task baseline suite.

## What the evidence shows

- **The failure is not universal.** GPT-OSS-120B and Nemotron Super VL each passed four matched seeds in both rounds. Groq Qwen passed three matched seeds in both rounds. The production fixture transport and scorer can succeed.
- **Groq GPT-OSS-20B has a repeated protocol problem.** All ten direct answers were correct, while all ten B cases received HTTP 400 with `tool_use_failed`. The provider said tool choice was none while the model called a tool. This is strong evidence for testing native tool calling separately.
- **The selected local models struggled even without tool orchestration.** All forty local A cases failed answer or format checks. Llama-2 also timed out in all ten B cases. Qwen's ten B cases failed the response contract. Dolphin's ten B cases ended incomplete nine times and timed out once. Gemma returned incorrect B answers six times, timed out three times, and ended incomplete once.
- **The saved answers explain specific failures.** On seed 1, GPT-OSS-120B returned the correct net total of 44 but a parts subtotal of 37 instead of 32. Local Qwen returned net total 40 and parts 37. Its B responses repeatedly combined actions and invented observations, which the parser rejected without executing those blocks.
- **Temperature zero did not ensure identical outcomes.** GPT-OSS-120B retained 4/5 A successes but changed which seed failed. Nemotron Lightning passed one B seed in round one and two different B seeds in round two; it had no matched B seed that passed twice. Thirteen of its twenty cases reached the output limit.

## Follow-up supported by the study

Use GPT-OSS-120B and Nemotron Super VL as positive controls for subsequent engineering checks, while retaining the unchanged scorer. Implement a separate native-tool arm C for providers/models that support it, starting with the GPT-OSS-20B protocol rejection. Keep transport/protocol errors, quota limits, output exhaustion and wrong answers separate. Test reasoning/output-budget changes as a new controlled experiment rather than changing limits within this study. Broader reliability requires the other baseline tasks and more repetitions.
