Quick start — running a local model

  1. Open LM Studio, load a model, and start its local server.
  2. Set Backend to lm_studio and Base URL to http://localhost:1234/v1.
  3. Set Model to local-model, or the exact name LM Studio shows.
  4. Leave Planner on react — it is the right default when tools are enabled.
  5. Tick the Tools the agent is allowed to use.
  6. Write a Task, then press Run Agent.

Click the ? beside any field for an explanation and worked examples.
